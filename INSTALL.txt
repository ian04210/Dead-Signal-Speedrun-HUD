Dead Signal Speedrun v0.9 — PRE-RELEASE

Requires: Dead Signal on Windows and UE4SS v3.0.1.
UE4SS releases: https://github.com/UE4SS-RE/RE-UE4SS/releases/

1. Close Dead Signal.
2. Install UE4SS v3.0.1 in DeadSignal\Binaries\Win64 using UE4SS's official instructions.
3. Download DeadSignalSpeedrun_v0.9.zip from the GitHub Release's Assets section.
   Do not use GitHub's automatic "Source code (zip)" download for installation.
4. Remove any previous Win64\Mods\DeadSignalSpeedrun folder (do not merge versions).
5. Extract the new DeadSignalSpeedrun folder from the ZIP into Win64\Mods.
6. Add DeadSignalSpeedrun : 1 to Win64\Mods\mods.txt.
7. Disable any old DeadSignalMenuProbe mod if you used it during testing.
8. Launch Dead Signal, select New Game > Speedrun, and press Begin Shift.

RTA counts continuously; estimated IGT is shown at pause/loading checkpoints.
There are no manual timer start/stop hotkeys in this build.

To uninstall: close the game, remove Win64\Mods\DeadSignalSpeedrun,
and disable or remove its line in Mods\mods.txt.

PRE-RELEASE WARNING:
The correct stop point at the successful ending fade has NOT been verified.
Estimated IGT is NOT an officially validated leaderboard timing method.
