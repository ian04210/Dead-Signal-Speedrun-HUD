Dead Signal Speedrun v1.0 — Release Candidate 2 (testing build)

Requires: Dead Signal (tested on 2.0.0) and UE4SS 3.0.1 (Windows).
UE4SS download: https://github.com/UE4SS-RE/RE-UE4SS/releases/

1. Close Dead Signal.
2. Install UE4SS 3.0.1 to DeadSignal\Binaries\Win64 if you haven't already.
   Follow UE4SS's own installation guide for its DLL files.
3. Remove any OLD DeadSignalSpeedrun folder from Win64\Mods (do not merge versions).
4. Copy the DeadSignalSpeedrun folder from this ZIP to Win64\Mods.
5. Enable it in Win64\Mods\mods.txt by adding: DeadSignalSpeedrun : 1
6. If you previously installed DeadSignalMenuProbe, disable it.
7. Launch Dead Signal, select New Game > Speedrun, and press Begin Shift.

Both timers should begin at Begin Shift. RTA advances live; estimated IGT
updates visually at pause/loading checkpoints. No manual timer hotkeys.

Uninstall: close game, delete Win64\Mods\DeadSignalSpeedrun, and remove
(or disable) its entry in mods.txt. UE4SS is a separate dependency.

IMPORTANT: Successful-run end-of-timer accuracy is still being verified.
This build should NOT yet be advertised as an approved leaderboard timer.
